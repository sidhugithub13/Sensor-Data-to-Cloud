# Sensor-Data-to-Cloud

The objective is to write arduino sensor data to clou using sensor device to get data.

**Hardware Requirements:**
1x Arduino Uno,
1x OHT2 temperature and humidity sensor,
1x ESP8266 WiFi module,
ThingSpeak Cloud Storage
Jumper Wires
